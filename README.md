# ⚾ ミニ野球 — パワプロ風ベースボール

ブラウザだけで遊べる、パワプロ風の野球ゲームです。
ビルド不要・依存ライブラリなし（HTML + CSS + 純粋な JavaScript / Canvas）。

## 遊び方

1. `index.html` をブラウザで開くだけ。
   - もしくはローカルサーバ経由（推奨）：
     ```bash
     cd mini_baseball
     python3 -m http.server 8000
     # ブラウザで http://localhost:8000 を開く
     ```
2. タイトル画面で **スペースキー** を押すと試合開始。

あなたは **ホームチーム**。3イニング制で、各回の
**表はあなたの投球（守備）／裏はあなたの打撃（攻撃）** です。

スマホ（タッチ）でもPC（キーボード/マウス）でも遊べます。画面サイズに
合わせてプレイ領域が自動で拡大・縮小し、縦長スマホでは縦長の画面になります。

## 操作方法

### 打撃（裏の攻撃）
- **画面をなぞる** / **← → ↑ ↓** … ミートカーソルを動かす
- **スイングボタン（右下）** / **スペース** … スイング

投手の球種とコースを読み、向かってくるボールにミートカーソルを合わせ、
ちょうど本塁に到達するタイミングでスイングします。
**カーソルの位置（空間）** と **スイングのタイミング** の両方が良いほど、
強い当たり（長打・ホームラン）になります。

### 投球（表の守備）
- **球種ボタン（左上）** / **1〜4** … 球種を選択
  - `1` ストレート / `2` カーブ / `3` スライダー / `4` フォーク
- **画面をなぞる** / **← → ↑ ↓** … 狙うコースを動かす
- **投球ボタン（右下）** / **スペース** … 投球

打球がフェアになると俯瞰ビューに切り替わり、**守備9人（投・捕・一・二・
三・遊・左・中・右）** と打球・走者が表示されます。

球種ごとに球速と変化（曲がり方）が異なります。
ストライクゾーンの隅を突いたり、変化球で打者のタイミングを外しましょう。

## ルール

- 3イニング制（同点の場合は延長）
- ボール4つでフォアボール（押し出しあり）
- ストライク3つで三振、ファウルは2ストライクまで
- アウト3つで攻守交代
- ヒット時はフィールド俯瞰ビューに切り替わり、打球と走者を表示
